## Known operating constraints

Use one application process for the file-backed settings writer and historical ledger; multi-instance deployment needs shared private storage and a controlled writer. SMTP/outreach delivery is at-least-once; ambiguous provider acceptance can produce duplicate messages, while database operation keys prevent duplicate collected units. CSP now uses script nonces and removes eval/broad script sources; legacy inline event attributes/styles and the narrowly allowed map library remain compatibility constraints documented in SECURITY.md. No local test certifies clinical outcomes, all device combinations or production capacity.
