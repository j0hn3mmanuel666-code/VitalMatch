Inter 4.1 is hosted locally so the interface does not need an external font service.

- Upstream: https://github.com/rsms/inter/tree/v4.1/docs/font-files
- Files: `InterVariable.woff2` and `InterVariable-Italic.woff2`
- License: SIL Open Font License 1.1; see `Inter-LICENSE.txt`.

The shared `/css/typography.css` defines the regular, medium, semibold, and bold weights. Italic is available for semantic emphasis using the same Inter family.
